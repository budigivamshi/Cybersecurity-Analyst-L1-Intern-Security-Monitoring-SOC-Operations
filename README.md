## 🚨 Incident Investigation Workflow

1. Receive security alert
2. Validate the alert
3. Identify affected host/user
4. Analyze relevant logs
5. Investigate IP, domain, URL or hash
6. Correlate multiple data sources
7. Determine true/false positive
8. Assess severity and impact
9. Escalate or contain according to the procedure
10. Document findings in Jira/ITSM
